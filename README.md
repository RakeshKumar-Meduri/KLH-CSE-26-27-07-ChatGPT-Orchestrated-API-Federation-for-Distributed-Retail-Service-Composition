## Abstract
Modern online retail platforms handle diverse operations such as product discovery, customer management, inventory tracking, shopping cart management, order processing, payment handling, and notifications. Traditional e-commerce systems often suffer from tightly coupled components, making coordination complex and user interaction cumbersome.

This project proposes an **intelligent distributed shopping architecture** that integrates **Generative AI (ChatGPT)** with a **microservice-oriented system**. The solution is designed to:
- Decompose retail functionalities into independent microservices (User, Product, Inventory, Cart, Order, Payment, Notification).
- Provide a unified entry point via an API Gateway and service discovery.
- Enable natural-language interaction through ChatGPT, allowing customers to express requirements conversationally.
- Implement adaptive service composition to dynamically coordinate multiple services based on user intent.
- Aggregate responses into intuitive conversational outputs.

The expected outcome is a **modular, maintainable, and intelligent retail platform** that transforms natural-language customer requirements into coordinated microservice operations, improving flexibility and user experience.
